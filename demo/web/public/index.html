  1. Solving Your browser works through a proof-of-work puzzle.
  2. Admitted The issuer checks the work and returns a one-use admission code.
  3. Token obtained A blind-signed Privacy Pass token the issuer can’t link to you.
  4. Access granted The protected page accepts the token.
  5. Replay refused The same token is sent again and turned away.

What this shows

  • Effort, not identity

    You spend a few seconds of computing. No account, email or cookie is asked for.

  • Can’t be linked to you

    The issuer signs the token without seeing it, so it can’t tell later whose token it was.

  • Works once

    Each token opens the page a single time. Use “Try replay” to see a second try refused.

Experimental demo, not a production service. The puzzle runs in your browser. Tokens are kept in memory only and discarded when you start again or leave.

Privacy Pass (RFC 9578, type 2 blind RSA) · self-hosted ALTCHA proof-of-work · no third-party requests
